# Build a Modern Student–Industry Mentor Platform

You are an expert full-stack product engineer, UI/UX designer, and software architect.

Build a **production-quality, modern web application** that connects students with verified industry professionals for mentorship sessions.

The product name is **MentorBridge**.

Tagline:

**"Connect. Learn. Grow."**

The platform should feel like a modern combination of a professional networking platform, mentorship marketplace, scheduling platform, and career development application.

Do NOT create a basic college-project-looking website. The UI should look polished, modern, professional, responsive, and ready for a real startup product.

---

# 1. PRODUCT GOAL

Students should be able to:

1. Create an account.
2. Build a student profile.
3. Select career interests and goals.
4. Discover industry professionals.
5. Search and filter mentors.
6. View detailed mentor profiles.
7. See mentor expertise, experience, ratings, pricing, and availability.
8. Book mentorship sessions.
9. Communicate with mentors.
10. Attend online mentorship sessions.
11. Receive resources and session notes.
12. Rate and review mentors.
13. Track career progress.
14. Get personalized mentor recommendations.
15. Eventually use AI-powered career tools.

Mentors should be able to:

1. Create professional profiles.
2. Add company, job title, experience, skills, and biography.
3. Set availability.
4. Create different mentorship session types.
5. Set pricing.
6. Accept/manage bookings.
7. Communicate with students.
8. Conduct mentorship sessions.
9. Share resources.
10. Track sessions and earnings.
11. Receive ratings and reviews.

Administrators should be able to:

1. Manage students.
2. Manage mentors.
3. Verify mentors.
4. Manage bookings.
5. Manage reports.
6. Manage categories and skills.
7. View platform analytics.
8. Manage platform content.

# 28. SECURITY

Implement security-conscious architecture.

Requirements:

- Never expose secrets to client-side code.
- Use environment variables.
- Validate user input.
- Use role-based authorization.
- Students must not access admin pages.
- Mentors must not access other mentors' private dashboard data.
- Users should only access their own private information.
- Validate uploaded files.
- Do not trust client-side role information.
- Use server-side authorization for protected operations.
